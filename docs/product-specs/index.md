## 写规格的约定

- 一份规格对应一个领域，不按页面切分（页面会变，领域不会）。
- 每份必须有「**用户可见行为**」一节：写清用户看到什么、能做什么，不写技术实现。
- 技术实现写在 `ARCHITECTURE.md` 或代码注释里，不重复。
- 决策与理由写在这里；纯技术选型写在 `design-docs/`。
- 状态变化时更新本索引表。
