## 用户可见行为

每个项目展示需求文档 §4.2 规定的九个字段：

| 字段         | 说明                                    |
| ------------ | --------------------------------------- |
| 名称         | 项目名                                  |
| 简介         | 一句话                                  |
| 要解决的问题 | 为什么做                                |
| 我的职责     | 我负责哪部分（**必须区分自研与 fork**） |
| 使用技术     | 技术栈                                  |
| 项目成果     | 可量化的结果                            |
| 截图或演示   | 影像                                    |
| 项目链接     | 在线地址（可选）                        |
| 代码仓库链接 | 仓库地址（可选）                        |

## 内容来源与边界

素材来自用户的本地项目与简历。**以下约束在实施时必须遵守**：

### 可以展示的

| 项目                        | 依据                                                                         |
| --------------------------- | ---------------------------------------------------------------------------- |
| 智能海关报关单证处理系统    | `/mnt/d/code/简历/1.md` 有完整描述，是实习期间的真实工作                     |
| 气体泄漏监测系统            | 实习二的工作，有 YOLOv8 检测与改进检测头的真实细节                           |
| iHeNovel（AI 小说创作助手） | 个人项目，真实存在。**但磁盘上无任何截图或界面图**，需用户补充或改用文字描述 |
| 语音助手意图识别与工具调用  | 实习一的真实工作                                                             |
| 简历解析系统                | `resume-analysis-system-master`                                              |

### 有风险的、需处理的

| 项目                                               | 问题                                                                                         |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `galaxy-assistant-dev_assistant`                   | **是 `xinnan-tech/xiaozhi-esp32-server` 的 fork / 衍生，不是原创作品**，不得作为个人项目展示 |
| `dana-declaration`                                 | 含硬编码真实 API 密钥（见 `../SECURITY.md`），展示前必须逐文件扫描                           |
| `resume-analysis-system-master/Assets/result1.png` | **含他人简历个人信息**，需脱敏或改造后才可展示                                               |
| `Resume_ner`                                       | 806 MB，体积几乎全在模型权重，不适合作为展示素材                                             |

### 诚实性要求

`/mnt/d/code/简历/1.md` 中有一条作者自注：面试时需说明**未实现智能路由与自动故障转移**。

**项目描述不得夸大已实现的功能。** 这是产品判断力问题，不是技术问题：招聘方会问细节，夸大的描述在追问下会崩。
