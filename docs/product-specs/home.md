## 用户可见行为

### 首屏：百叶窗

进入站点即看到一屏满幅影像，画面被 14 条横缝切开，模拟《教父》书房那场戏的百叶窗光带。

向下滚动依次推进五幕，每幕换影像与文字。换幕时横缝轻微合拢再展开，图片本身不移动、不重排。

| 幕  | 年份    | 文字                      | 出处标注                           |
| --- | ------- | ------------------------- | ---------------------------------- |
| 1   | 1945    | 本纳瑟拉的 / 女儿被打了。 | 《教父》三部曲全景笔记 · 第 41 行  |
| 2   | 1945 冬 | 橙子滚了 / 一地。         | 视听语言 · 第 1 个符号 · 第 764 行 |
| 3   | 1951    | 五大家族 / 坐在一起。     | 编年史 · 第 699 行                 |
| 4   | 1955    | 他在教堂里 / 否认撒旦。   | 视听语言 · 第 2 个符号 · 第 773 行 |
| 5   | 1997    | 院子里 / 没有人。         | 编年史 · 第 708 行                 |

右侧有五个年份索引，可点击跳转到对应幕；当前幕的索引线加长。底部显示所在幕的序号与三条事实（`827 行` / `11 章` / `80 张影像`）。

### 首屏之下

- **计数行**：笔记 67 篇、影像 412 张、整理跨度 2024 至 2026、《教父》笔记 827 行。
- **同一批笔记，四种结构**：并置三种真实版式，证明「同样是笔记，结构不一样」——论坛讨论（楼层对置）、科普速查（判定表）、技术长文（目录脊）。
- **入口**：一个指向全部笔记的按钮。

## 必须遵守

- 首屏文字**只陈述事实**，带可核对出处。禁止解读、总结、自我拔高（用户 m00173 / m00178 / m00250）。
- 五幕文字与出处标注**已通过用户复核**，不得擅自改写（用户 m00250：「现在的可以」）。
- 影片版权风险由用户确认承担（`../requirements.md` §5.2）。

## 验收方式

```bash
pnpm build && node scripts/verify-dist.mjs
```

断言：五幕均可到达、无横向溢出、无页面错误、`reduced-motion` 下退化为静态首屏、字体的计算值非空。
