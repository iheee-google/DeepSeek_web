## 用户可见行为

### 列表页

按**体裁**而非时间倒序组织。每篇显示标题、日期（或「未标注」）、分区、标签。

### 六种版式

**不同体裁不套统一模板**（用户 m00250 决策）。版式由 front matter 的体裁判定结果决定：

| 体裁                | 版式                           | 为什么                                         |
| ------------------- | ------------------------------ | ---------------------------------------------- |
| `thread` 论坛讨论   | 楼层号在左沟槽，立场与原文在右 | 内容是「谁在第几楼反驳谁」，平铺会丢掉对话结构 |
| `glossary` 科普速查 | 表格当主角                     | 全文结论落在一张表上                           |
| `longform` 技术长文 | 目录脊 + 正文                  | 761 行的文章需要不打断阅读的导航               |
| `product` 产品记录  | 版本时间线 + 截图横向轨道      | 截图与版本号本身就是正文                       |
| `essay` 理论随笔    | 定义与对照                     | 围绕概念展开                                   |
| `index` 目录索引    | 简洁列表                       | 索引页不是内容                                 |

### 日期显示

**不存在可信的统一创建日期**。显示规则：

| 来源                                   | 显示                                          |
| -------------------------------------- | --------------------------------------------- |
| front matter `created`                 | 直接显示（仅 2 篇有）                         |
| 粘贴图文件名 `image-YYYYMMDDHHMMSSmmm` | 显示，标注来源                                |
| 原帖的保存时间 / 整理时间              | 显示，标注来源                                |
| 无任何日期信号（41/67 篇）             | 归入「未标注」分组，**不得用文件 mtime 兜底** |

### 旗舰条目：《教父》三部曲

作为笔记栏目下的旗舰内容公开展示，含 80 张影像。其内部再分：

- 827 行全景笔记全文（11 章）
- 人物图鉴（44 人，六个分组）
- 编年史时间轴（1901–1997，13 个时间节点）
- 视听语言 12 个符号

编年史与人物图鉴使用**滚动驱动的排列重组**（原 β 原型机制，用户确认保留给笔记页）。
