## 用户可见行为

### 列表页

按**体裁**而非时间倒序组织。每篇显示标题、日期（或「未标注」）、分区、标签。

### 六种版式

**不同体裁不套统一模板**（[`../requirements.md`](../requirements.md) §5.7，用户 2026-10-12 第三次提出的硬约束）。版式由 front matter 的体裁判定结果决定：

**差异的粒度是「主题」，不是「单篇」**：主题型笔记（电影观后感一类）每个主题一套 UI —— 《教父》一套，后续的《风骚律师》《绝命毒师》各是独立主题；技术型笔记（本表六种体裁）本阶段先保持一致，同体裁共用一套版式。

| 体裁                | 版式                           | 为什么                                         |
| ------------------- | ------------------------------ | ---------------------------------------------- |
| `thread` 论坛讨论   | 楼层号在左沟槽，立场与原文在右 | 内容是「谁在第几楼反驳谁」，平铺会丢掉对话结构 |
| `glossary` 科普速查 | 表格当主角                     | 全文结论落在一张表上                           |
| `longform` 技术长文 | 目录脊 + 正文                  | 761 行的文章需要不打断阅读的导航               |
| `product` 产品记录  | 版本时间线 + 截图横向轨道      | 截图与版本号本身就是正文                       |
| `essay` 理论随笔    | 定义与对照                     | 围绕概念展开                                   |
| `index` 目录索引    | 简洁列表                       | 索引页不是内容                                 |

### 日期显示

**不存在可信的统一创建日期**。2026-10-12 实测 67 篇的信号分布（按本表的优先级取第一个命中的来源）：

| 来源                                   | 篇数 | 显示                                      |
| -------------------------------------- | ---- | ----------------------------------------- |
| front matter `created`                 | 2    | 直接显示                                  |
| 原帖整理时间 `整理时间`                | 1    | 显示，标注来源                            |
| 原帖保存时间 `保存时间`                | 7    | 显示，标注来源                            |
| 粘贴图文件名 `image-YYYYMMDDHHMMSSmmm` | 26   | 显示，标注来源                            |
| 无任何日期信号                         | 31   | 归入「未标注」，**不得用文件 mtime 兜底** |

> 本表原先写作「无任何日期信号（41/67 篇）」。2026-10-12 用 `scripts/` 口径重数，实测为 **31 篇**（`保存时间` 与 `整理时间` 有重叠，按上表优先级去重后才是这个数）。未标注的 31 篇集中在 `工作`（6/6）、`毕设`（7/7）、`面试`（2/2）三个目录。

### 旗舰条目：《教父》三部曲

作为笔记栏目下的旗舰内容公开展示，含 80 张影像。其内部再分：

- 827 行全景笔记全文（11 章）
- 人物图鉴（44 人，六个分组）
- 编年史时间轴（1901–1997，13 个时间节点）

编年史与人物图鉴使用**滚动驱动的排列重组**（原 β 原型机制）。2026-10-12 用户明确表示「我很喜欢 β」，并要求把 α/β/γ 这类机制放在**笔记页**而不是首页。
