# 设计规范

## 1. 方向

**「证据剧场」**：真实影像 + 大字号标题压印 + 滚动驱动推进。

冲击力来自**真实影像与内容的密度**，不来自装饰。全站无渐变装饰、无发光、无粒子。

### 1.1 验收标准（用户原话）

> 这个我不清楚，反正我的需求很明确：**高级感、设计感、艺术感、动态感，要给点进来的用户一个巨大的视觉冲击。**

来源见 [`requirements.md`](./requirements.md) §5.3.1（旧会话 `session-1fe6db04` 第 1 轮 `ask_user_question` 的 `stack` 题自定义回答）。

**四个词加一个冲击，逐条对号**：这份规范里的每一个决定，都要能回答它服务于哪一条。

### 1.2 明暗基调

**浅色是主方案**（用户 m00695）。深色是可选的第二主题，不是设计起点。
本文件 §5 的高调白场取代 2026-10-11 的深棕黑底方案。

## 2. 已否决的通用方案

以下两类方案被明确否决，不得回流。两者的共同问题是**任何作品集站点都能用**，不构成辨识度。

| 否决对象                                                          | 原因                                                                     |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 暖奶油底（近 `#F4F1EA`）+ 高对比衬线 + 陶土强调色（近 `#D97757`） | 当下生成式设计的头号配色特征                                             |
| 近黑底 + 单一亮强调色（酸性绿 / 朱红）                            | 与 §1.2 的浅色基调冲突；且该组合是「高级感」的捷径，不是高级感本身       |
| 纯网格 + 编号 + 等宽字体的「技术档案馆」                          | 理性但情绪浓度低，达不到要求的视觉冲击                                   |
| SaaS 卡片套件（同圆角、同柔和阴影、内容切成等大卡片）             | 通用默认，无内容呼应                                                     |
| 模板化 chrome：全大写拉开字距的 eyebrow、中点连接的 meta、`词 — 短语`式标签、`#0B0B0B` 冒充黑、等宽小标签、链接尾缀 `→` | 与题材无关的通用装饰 |

> **被否决的是这些方案组合，不是用户的词。**「高级感」是用户提出的**要求**（§1.1）；
> 2026-10-11 的规范把它写成「要避免的东西」，属于把用户的标准读反了。已更正。

## 3. 核心机制：百叶窗

首屏机制来自素材本身，不是装饰。

- `scenes/office-vito.jpg` 与 `portraits/vito.jpg` 是**同一场戏的两种裁切**，画面骨架是**横向百叶窗切出的光带**。
- 实现用**一条 CSS mask**（`mask-image` + `mask-size:100% calc(100%/14)` + `mask-repeat:repeat`）复现 14 条横缝，而非 14 个 DOM 节点。理由：DOM 节点方案在切换时要重排 14 个元素，mask 方案只改一个自定义属性。
- 换幕只切横条透明度与轻微合拢，**图片不换位置、不重排**。
- 展开动画用 `@property --slat` 注册为 `<percentage>` 做插值。**必须注册为 `<percentage>`**：注册成 `<length>` 时含百分号的 calc 无法插值，动画静默失效。

## 4. 排版

| 项           | 规则                                                                          |
| ------------ | ----------------------------------------------------------------------------- |
| 中文字体     | Noto Serif SC（正文与标题）/ Noto Sans SC（界面小字）。两字体均为 SIL OFL 1.1 |
| 构建字体     | 构建期按实际字符集子集化为 woff2（24 MB → 134 KB），**不直接引全量 TTF**      |
| 行宽         | 正文默认 < 80 字符                                                            |
| 标题         | 只陈述事实或省略；禁止排比、对仗、「这就是……」式总结、替读者解读、伪造金句    |
| 标点         | 标题可省句末标点（用户 m00625）。正文标点正常                                 |
| eyebrow 标签 | **禁止**标题上方的全大写拉开字距小标签                                        |
| 编号标记     | 只在内容真的是序列时使用                                                      |

## 5. 配色

**高调白场（light-key）**。取代 2026-10-11 的深棕黑底方案（用户 m00695：`尽量不要暗色系的`）。

| Token         | 值        | 用途                                                                     |
| ------------- | --------- | ------------------------------------------------------------------------ |
| `--paper`     | `#FFFFFF` | 页面底。**真白**                                                         |
| `--wash`      | `#F1F1EF` | 抬升面。**冷中性**灰白——刻意不偏暖，偏离 `#F4F1EA` 奶油色反模式         |
| `--ink`       | `#14110F` | 主文字。微暖近黑，**只用于文字，不作背景**                               |
| `--ink-2`     | `#57534D` | 次要文字                                                                 |
| `--ink-3`     | `#8B8781` | 第三级文字、元信息                                                       |
| `--rule`      | `#DEDDD8` | 发丝分隔线                                                               |
| `--vermilion` | `#D4370F` | 唯一合成彩色。**只用于状态与交互**（当前项、焦点环、链接 hover），面积始终很小 |

### 5.1 大面积的颜色只来自影像

页面本体是白纸与墨字。**唯一的大面积浓色是真实影像**——教父剧照的钨丝暖调。

这是「证据剧场」在浅色下的解法：暗色剧场里光是唯一的彩色，高调白场里影像是唯一的彩色。
两种写法同一条原则：**颜色必须是内容，不是装饰**。

因此全站不使用大面积合成色块。`--vermilion` 在一屏内的覆盖面积始终小于 2%。

### 5.2 对比度（实测值，非估算）

由 `scripts/verify-home-prototypes.mjs` 读取计算后的前景/背景色并按 WCAG 2.1 公式计算：

| 组合                          | 实测对比度 | AA 正文（4.5:1） |
| ----------------------------- | ---------- | ---------------- |
| `--ink` on `--paper`          | 见验证输出 | 通过             |
| `--ink-2` on `--paper`        | 见验证输出 | 通过             |
| `--vermilion` on `--paper`    | 见验证输出 | 见输出（用于大字号或图形时按 3:1 判定） |

## 6. 文案规则（硬约束）

由用户 m00173 / m00178 / m00250 三轮反馈确立，已被结构测试机械校验。

- 界面标题**只陈述事实或直接省略**。
- 禁止：排比、对仗、「这就是……」式总结句、替读者解读、伪造金句。
- 禁止标题上方全大写 eyebrow 小标签。
- 文案尽量带**可核对出处**：首屏每屏右下角标注原文行号或章节，如 `视听语言 · 第 1 个符号 · 第 764 行`。
- **禁止英文 em-dash 与 en-dash**（中文破折号「——」不在禁令内）。

## 7. 反面清单（Pre-Flight）

提交视觉改动前逐条自查（★ = 已被 `tests/structure/layout.test.ts` 机械校验，扫 `src/` 与 `prototypes/`；其余靠人看）：

- [ ] 没有装饰性渐变、发光、粒子
- [ ] 没有「近黑底 + 单一亮强调色」的整体观感
- [ ] 没有同圆角同阴影的卡片套件

- [ ] 标题上方没有 eyebrow 标签
