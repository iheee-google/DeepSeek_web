# 产品判断力

> 这份文档记录**取舍标准**，而不是功能清单。功能清单在 [`requirements.md`](./requirements.md)、
> 规格在 [`product-specs/`](./product-specs/)。

## 1. 这个站点是什么

一个人的长期内容空间，同时兼任简历与作品集。**不是**博客，**不是**作品集模板站。

三种读者，优先级从高到低：

| 读者            | 停留多久       | 要什么                           |
| --------------- | -------------- | -------------------------------- |
| 招聘方 / 合作方 | 30 秒到 3 分钟 | 这人能做什么、做过什么、怎么联系 |
| 感兴趣的人      | 5 到 30 分钟   | 真实的东西：影像、笔记、判断     |
| 未来的自己      | 数年           | 结构还在、内容还能找到           |

**两类读者的需求会冲突**：招聘方要快速结论，感兴趣的人要深度。解决方式是**分层而非折中**——首屏给冲击与事实，往下给密度，深处给全文。不为照顾前者而把后者压扁。

## 2. 取舍标准

### 加一个东西之前问

1. **它是内容还是装饰？** 装饰一律不加。冲击力来自真实影像与内容密度，不来自渐变、发光、粒子。
2. **它能在多少站点上原样出现？** 能出现在任何作品集上的东西，不构成辨识度，不加。
3. **没有它，内容是否仍然完整可读？** 如果完整，它是装饰。
4. **它服务哪一类读者？** 说不出就说明没想清楚。

### 删一个东西之前问

1. **它承载的是事实还是感受？** 事实保留（年份、出处、行号、计数）。
2. **删掉后有无内容失去入口？** 有就保留。

## 3. 界面文案的判断标准

这是本项目踩坑最多的地方（用户 m00173 / m00178 / m00250 三轮反馈）。

| 做法                                       | 判定                |
| ------------------------------------------ | ------------------- |
| `本纳瑟拉的女儿被打了。`                   | ✅ 陈述事实，可核对 |
| `橙子滚了一地。`                           | ✅ 陈述画面         |
| `两条线的长度差，就是这个网站的全部内容。` | ❌ 替读者下结论     |
| `你唯一无法被复制的东西是……`               | ❌ 伪造金句         |
| `22 岁。整理了 96 年。`                    | ❌ 对仗 + 自我拔高  |

**判据：把这句话念给一个不认识作者的人听，他会不会觉得作者在推销自己？** 会，就删。

文案尽量带**可核对出处**（`视听语言 · 第 1 个符号 · 第 764 行`）。出处让陈述变成证据，也让读者能自己去查。

## 4. 内容边界

| 内容                     | 决策                                | 理由                                             |
| ------------------------ | ----------------------------------- | ------------------------------------------------ |
| 《教父》笔记含 80 张影像 | 公开展示                            | 用户明确授权（m00061、m00152 Q12=B）             |
| linux.do 帖子 8 篇       | 首批全部上线                        | 用户确认全部为本人所写，含小号（m00152 Q14/Q15） |
| 简历                     | **拆分进网页结构，不提供 PDF 下载** | 用户 m00152 Q10                                  |
| 原创声明 / 版权页脚      | 不加                                | 用户 m00152 Q6                                   |
| 长文笔记                 | 保持中文                            | 用户 m00152 Q16                                  |
| 界面与职业信息           | 中文优先，双语留接口                | 用户 m00152 Q16                                  |

### 必须处理的敏感项

以下内容**展示前必须脱敏**，否则不得上线：

- linux.do 帖子含大量**真实论坛用户名**（企业知识库 15+、LangGraph 20+）。
- `source_path` 字段含本机 D 盘绝对路径。
- `/mnt/d/code/简历/resume-analysis-system-master/Assets/result1.png` 含**他人简历个人信息**（姓名、电话、邮箱、出生年月、毕业院校）。**不得直接展示**，需脱敏或改造。
- 三处硬编码真实 API 密钥（详见 `SECURITY.md`）。用户当前决策为暂不处理（m00152 Q13=C），**任何情况下都不得把这些文件或其内容发布到站点**。

## 5. 什么不做

明确排除，避免反复讨论：

- 不做暗色/亮色双主题的全套设计（首版只有深色；系统跟随留待后续）。
- 不做评论区、不做点赞、不做访问统计展示。
- 不做博客式的时间倒序信息流当首页。
- 不为每一篇笔记做一套独立设计——按**体裁**归并为六种版式。
- 不追热点技术栈；技术栈已冻结。
