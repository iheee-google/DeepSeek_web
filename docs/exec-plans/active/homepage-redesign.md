现首页把**一篇笔记**（《教父》三部曲的百叶窗影像）当成了整个站点的门面。这与用户 2026-10-11 自己给出的两条回答直接冲突：

同时，`requirements.md` §5.5 原先记录的「用户已在看过三个方向原型后确认选定 γ」经逐条核对全部用户消息后确认**从未发生**（该节已改正）。也就是说：现首页不仅选错了内容，连"这是用户选的"这个前提本身也是假的。

用户对"首页该怎么做"的选择是：**先做几个可打开的实物，看实物再定。**

## 2. 首页需要回答的问题

用户第 7 条回答明确说了访客是谁：

> 怎么说呢，你自己当做网友，而我是网站的主人，你觉得用什么内容去呈现好一点？网友不一定是招聘者啊。

所以首页**不以招聘流程为中心**。它要回答的是：

| #   | 问题                     | 谁在问       |
| --- | ------------------------ | ------------ |
| 1   | 这个人是谁、做什么的     | 任何访客     |
| 2   | 他做过什么、会做什么     | 网友、招聘方 |
| 3   | 还有什么可看的、从哪进去 | 愿意停留的人 |
| 4   | 怎么联系                 | 招聘方       |

## 3. 三个候选方向

**三个方向的差别是"首页把什么放在第一位"，不是配色。** 配色、字体、文案规则、动效 token 三案共用，见 §4。

### A「一条线」 —— 第一位是时间

首页是 2022.09 到现在的一条线。首屏是一条**按真实时间比例**绘制的横尺：`2022.09` 在左端、`现在` 在右端，中间的刻度按真实日期定位，间距就是真实的时间间隔（不是均分）。滚动时这条横尺收拢、落下，接成页面左侧的竖轴，之后每件事贴着轴展开。

- 首屏没有任何照片。整页的视觉重量压在字号与刻度上。
- 时间点、事、据三段式；每一段都可回到简历或笔记的原文。
- 记忆点是那条**真的**尺子。
- 适合的前提：这个人的价值主要在"持续做了多久"。若不成立，这一页会显得单薄。

### B「一件件」 —— 第一位是问题

首页不讲"我是谁"，讲**三件具体的事**。每条从事本身的开场：先给一个真实的技术处境，再给做法，再给可核对的结果。

- 首页第一句话是一个技术问题，不是自我介绍。名字与身份固定在顶栏。
- 金色只出现在"结果"的数字上，问题与做法保持普通文字色，于是强调色有了明确语法。
- 没有卡片、没有边框、没有阴影；条目之间只有一条发丝线。
- 记忆点是**开场那句具体的话**。
- 风险：访客如果想知道"这人是谁"，需要读三条才拼得出来。缓解方式是顶栏与最后一屏。

### C「一堆」 —— 第一位是体量

首页同时呈现全部家当的形状，不叙述。67 篇笔记按**真实行数**排成横条索引：954 行的 `apk签名` 是一条长条，17 行的 `向上取整` 是一小截。条长就是数据。

- 不按统一模板排列：`程序设计` 的 19 张卡片、`linuxdo帖子` 的 8 根长条、`目标检测` 的树、`毕设` 的 7 段链，各按自己的形状画。
- 首屏没有大标题，只有语料本身与一行必要的锚点。
- 记忆点是**页面尺寸即数据**。
- 风险：这一页偏"资料馆"，情绪浓度低；且笔记正文尚未接入仓库（技术债 D1），现在只能画骨架。

## 4. 三案共用、不参与比较的部分

放在这里是为了让用户的选择**只关于结构**，不必同时重新裁定配色。

| 项       | 取值                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 字体     | Noto Serif SC（标题与长文）/ Noto Sans SC（界面与元信息），两字体 SIL OFL     |
| 底色     | `#0B0907`（深棕黑，避开「近黑底」反模式）                                     |
| 主文字   | `#F0E9DB`；次要 `#A89E8F`；三级 `#6F665B`                                     |
| 唯一强调 | `#C39A45`，只进入可核对的事实：年份、出处、行数、指标                         |
| 发丝线   | `#2A2521`                                                                     |
| 动效     | 缓动与时长取自 `src/config/site.ts` 的 `MOTION`；只动画 `transform`/`opacity` |
| 文案     | 只陈述事实；无排比、无「这就是」总结、无伪造金句、无 eyebrow、无 emoji        |
| 图标     | Lucide 内联 SVG（ISC）                                                        |
| 降级     | `prefers-reduced-motion: reduce` 时保留透明度与颜色过渡，移除位移与缩放       |

**已知张力**：深底 + 单一强调色本身接近「反模式清单」里的第二条。选它是为了呼应《教父》剧照里钨丝灯与黄铜的实际颜色，且强调色被限制在"可核对的事实"上。若用户选定结构后想换配色，这属于下一轮独立决定，不阻塞本次裁定。
