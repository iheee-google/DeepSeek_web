# 统一档案辅助文字字号

## Goal

提高全文页顶栏、侧边目录及首页同类辅助文字的可读性，修复截图中“顶栏文字”和“目录文字”过小的问题，同时保持标题、正文、引文和页面结构稳定。

## Background

- 用户提供的两张截图分别显示全文页侧边目录和顶部导航；两处文字在视觉上明显小于页面的阅读正文。
- 当前实现位于 `notes.html` 和 `index.html` 的内嵌 CSS，没有共享外部样式文件。
- 在 Linux/Chromium、`document.fonts.status === "loaded"`、DPR 1 下，三个桌面 CSS viewport 的基线测量结果一致地显示：
  - `notes.html` 顶栏导航约 `10.9px`，返回入口约 `9.9px`，品牌英文副标题约 `7.7px`。
  - `notes.html` 目录一级约 `10.7px`、三级约 `9.8px`，目录标题约 `9.3px`，工具栏和统计标签约 `9.3–9.9px`。
  - `index.html` 顶部导航约 `10.6px`，按钮约 `11.5px`，时间轴/引用/人物等辅助标签约 `9.3–10.9px`，若干模块说明约 `11.8–12px`。
  - 全文正文为 `16px`，首页全文入口说明约 `15.2px`，这两类已有可读基线，不应被本次“放大辅助文字”机械扩大。
- CSSOM 只能确认声明字体栈和计算字号，不能证明所有平台最终采用的具体 CJK 字体；验收记录必须保留这一限制。
- 当前档案文字排版任务已经归档；本次是独立的辅助文字层级修正任务。

## Requirements

1. 在 `notes.html` 中放大并统一以下桌面文字层级：顶部导航、品牌辅助文字、返回入口、全文目录标题、目录一级/三级链接、工具栏元信息、继续阅读入口和统计标签。
2. 在 `index.html` 中盘点并放大与上述层级相当的文字：顶部导航、按钮文字、时间轴标签/操作入口、引文来源与索引、人物卡辅助标签、符号说明、页脚和全文入口统计标签等；已经达到正文可读尺寸的模块说明不重复放大。
3. 使用少量按语义命名的排版角色变量统一字号和行高，避免逐个元素设置互不一致的孤立数值。桌面端建议目标为：主导航/目录约 `14–16px`，次级目录和操作文字约 `13–15px`，元信息/辅助说明约 `12–14px`，纯装饰英文小标约 `11–13px`。
4. 仅在现有桌面边界（`min-width: 901px`）调整新增字号和配套间距；不新增移动端布局、移动端视觉设计、移动端截图或移动端验收。既有 `390×844` 图片查看器回归继续保留，但仍只作为历史防回归。
5. 放大后保持文字完整、自然换行和可访问性：顶栏不得重叠，目录长标题可换行且仍可滚动到全部条目，正文列不被侧栏挤压，页面不得出现横向溢出、裁切或新增孤立单字。
6. 保留现有 URL、稳定 ID、搜索/目录定位、交互、动画和 `prefers-reduced-motion` 行为。不修改 `content/`、`assets/data/archive.js`、生成器、图片或部署配置。

## Out of Scope

- 不改全文正文、首页主标题、主引文语义行组或源 Markdown 文案。
- 不把根元素字号整体缩放，不把所有小字无差别放大，不改变正文和表格的既有阅读层级。
- 不新增字体、框架、运行时依赖或外部 CDN。
- 不开发或验收手机/平板布局，不推送远程仓库，不执行 Cloudflare 部署。

## Acceptance Criteria

- [x] `notes.html` 顶栏和侧边目录在 `1920×1080`、`1440×900`、`1024×900` 三个桌面 CSS viewport 下明显大于当前基线，并达到对应语义角色的可读字号；顶栏文字、图标和返回入口不重叠。
- [x] `index.html` 中与全文页同层级的导航、按钮、标签、索引和辅助说明完成同类审查；达到正文可读尺寸的说明文字不被无必要放大。
- [x] 三个桌面 viewport 下全文页目录所有条目仍可见或可通过目录滚动访问，长目录链接自然换行，侧栏和正文无横向溢出，标题和引文既有行组不改变。
- [x] 新增或调整的 Playwright 断言覆盖字体加载完成、计算字号层级、顶栏几何、目录可滚动性和页面无横向滚动；不把具体字符数或脆弱像素断行写死。
- [x] 现有 `npm test`（含历史 `390×844` 图片查看器回归）、`npm run build`、相关 JavaScript 语法检查和 `git diff --check` 通过。
- [x] 复核 `1920×1080`、`1440×900` 首页与全文页截图，并对 `1024×900` 做桌面边界检查；记录 CSS viewport、DPR、字体加载状态和声明字体栈，不虚报实际渲染字体。
- [x] diff 仅包含 `index.html`、`notes.html`、必要的 `tests/desktop-smoke.spec.js`、本任务文档和 workspace journal；不改源内容、生成数据、图片或部署配置。

无。用户已确认按“全文页与首页同类辅助文字统一放大”的范围建立任务并实施。
