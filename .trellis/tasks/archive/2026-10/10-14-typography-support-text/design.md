# Design: 统一档案辅助文字层级

## Boundary

本任务只修改 `index.html`、`notes.html` 和桌面排版回归测试；必要时更新任务文档和 workspace journal。内容源、生成器、生成数据、图片、搜索定位、交互逻辑、部署配置和移动端布局均不在边界内。

正式验收视口为 `1920×1080`、`1440×900`，`1024×900` 为桌面边界检查。既有 `390×844` 图片查看器回归继续运行，但不构成移动端交付。

## Evidence and Problem Model

问题不是全文正文过小，而是辅助文字层级过度压缩：顶栏、目录、元信息和操作入口普遍落在约 `9–11px`。在当前 CSS 字体栈和 Linux/Chromium 基线下，全文正文已为 `16px`，首页全文入口说明约 `15.2px`，因此应分层修复，不能通过整体放大 `html`/`body` 或所有 `rem` 解决。

用户截图中的全文目录由 `.note-toc a` 和 `.note-toc a[data-depth="3"]` 渲染，顶栏由 `.notes-nav`、`.brand-copy` 和 `.notes-return` 渲染。首页存在同层级的 `.top-nav`、`.button`、`.timeline-item` 辅助标签、`.quote-source`、`.quote-index-button`、人物辅助标签、符号说明和页脚。

## Typography Roles

在两个页面各自已有的内嵌 CSS 中增加同名、少量的桌面角色变量，保持原生静态页面结构，不新增共享运行时层：

- `--archive-ui-nav-size`：主导航和主要入口，目标约 `14–16px`。
- `--archive-ui-toc-size`：全文目录一级文字，目标约 `14–16px`。
- `--archive-ui-toc-sub-size`：目录三级/次级条目，目标约 `13–15px`。
- `--archive-ui-action-size`：按钮、返回入口、继续阅读等操作文字，目标约 `13–15px`。
- `--archive-ui-meta-size`：统计、时间轴标签、引用来源和卡片辅助文字，目标约 `12–14px`。
- `--archive-ui-micro-size`：仅保留给英文 kicker、类别标记等纯装饰性短标签，目标约 `11–13px`。

变量只在 `@media (min-width: 901px)` 下用于本次桌面修正，避免把本次桌面视觉决策扩散到任务范围外的窄视口。各选择器保留原有颜色、字距、动画和语义结构。

## Layout Compatibility

- 全文页顶栏在桌面端增加与字号匹配的垂直内边距/最小高度，保留 sticky 定位；导航链接和返回按钮扩大点击区域而不改变 URL。
- 全文目录保持原有滚动容器和 Rail TOC 逻辑；必要时只调整一级列的最小可用宽度、链接内边距或行高，让放大后的长中文自然换行，不使用隐藏、裁切、省略号或全局 `nowrap`。
- 工具栏和统计标签允许按现有 flex/grid 规则换行；正文列保持 `minmax(0, 1fr)` 和既有最大阅读宽度。
- 首页只放大已盘点的同层级辅助文字；主标题、主引文和正文说明保持现有排版契约，避免引入新的标题断行或引文行组变化。

## Runtime and Accessibility

不改变 DOM 语义、稳定 ID、目录链接、搜索目标、交互状态或 reveal/reduced-motion 实现。字号调整不通过脚本实现，辅助技术继续读取现有完整文本；按钮和链接保持原有焦点路径。

## Verification Design

1. Playwright 在三个桌面 viewport 等待 `document.fonts.ready` 和现有 reveal 稳定后，检查两页实际计算字号达到角色下限；记录 `innerWidth`、`innerHeight`、DPR、字体状态和声明字体栈。
2. 检查全文页顶栏所有可见文本的几何边界互不重叠，目录链接存在、长条目可访问、目录滚动容器仍有完整滚动范围；页面和正文列无横向滚动。
3. 检查首页同层级辅助文字的字号角色、导航/按钮可见性和页面无横向溢出；已有标题 Range 行盒、引文行组和主引号回归继续由现有测试负责。
4. 运行构建、Playwright、JavaScript 语法和 `git diff --check`；截图只用于三个桌面视口的视觉确认，不将名义屏幕分辨率当作 CSS viewport。

## Implementation Result

- 两页都在现有桌面排版块中使用按语义命名的角色变量；没有新增共享运行时层，也没有改变源内容、稳定链接或交互脚本。
- 全文页顶栏从约 `9.3–10.9px` 的辅助文字提升到约 `11–16px` 的角色范围，目录一级/三级与工具栏分别提升并保留自然换行和滚动容器。
- 首页同层级导航、按钮、时间轴、引文、人物、符号、入口统计、搜索结果和页脚完成同类审查；正文说明、主标题、引文主显示和表格未被机械放大。
- `1920×1080`、`1440×900`、`1024×900` 均通过字号、顶栏几何、目录可达和无横向溢出检查；截图已复核。浏览器只报告声明字体栈，未把它当作实际 CJK 渲染字体结论。
- 收尾检查覆盖首页时间轴轨道、人物首排、引文主显示、页脚和全文目录末端；这些区域在 `1440×900` 的滚动截图和几何测量中均无自身横向溢出，页面整体无横向滚动。目录的激活项保留颜色/边框反馈，仅将桌面水平位移改为垂直位移以避免整宽链接制造滚动区。
- 搜索结果在三个桌面视口真实打开并输入“教父”后复核：结果内容列加入 `min-width: 0`，等待搜索壳体过渡到 `opacity=1`/`transform=none` 后严格检查搜索壳体和结果边界；标题/类型标签不得裁切，摘录保留原有显式 `nowrap + ellipsis` 契约，并检查其实际字号和可见尺寸。
- 目录截图验收不依赖固定延时：先等待激活项的目录自动跟随几何稳定，再让末项进入 viewport，连续确认目录 `scrollTop` 与末项 `top/bottom` 不再变化，使用该稳定状态截图。

## Trade-offs and Rollback

统一角色变量会同时调整多个同层级小字，可能增加目录高度、按钮宽度或某些卡片换行，但比逐个元素补丁更容易保持视觉层级一致。若某个局部容器因放大后拥挤，优先调整该容器的留白/可用宽度；不回退到过小字号或删除文字。回滚只需恢复两个页面的排版块和对应测试，不触及内容与生成数据。
