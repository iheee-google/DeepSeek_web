# 教父档案电影感与视觉冲击力重设计

## 目标与用户价值

上一版「暖纸与暗书房」已经完成暖纸阅读面、局部暗区和对比度验收，但用户实际查看后反馈“太平淡、视觉冲击力不够”。本任务将视觉重心从“统一配色”推进到“电影式构图与叙事节奏”：让首屏有第一视觉，让暗色成为权力节点，让人物/时间线/史实具有内容地图感，同时保持档案可读性和既有功能稳定。

## 基线与证据

- 当前基线是提交 `853fef6` 的「暖纸与暗书房」主题；实际 1440×900 首页截图显示暖纸导航、近黑首屏、左侧大标题和右侧三张海报。色彩已统一，但标题、海报、留白和模块之间的戏剧关系不足。
- 当前首页已有 `.hero`、`.hero-media`、`.hero-poster`、`.quote-section`、`.timeline-section`、`.finale` 等暗面/影像结构；`index.html:187–300`、`423–500`、`492–500` 是首轮构图与影像重点位置。
- 当前规则、时间轴、人物、史实、符号大多使用均匀的亮面模块与重复网格/带状结构；这保证阅读稳定，但会削弱叙事高潮和权力空间的区别。
- Gordon Willis 的采访把《教父》视觉描述为 brown-and-black，偶尔接近 blue-black，并明确区分纽约、西海岸与西西里的质感；这支持局部暗切和场景差异，不支持全站统一黑滤镜。研究证据见 `research/visual-impact.md`。
- 编辑式暗色参考支持多层近黑、非对称网格、大比例影像、极大标题和克制酒红/象牙标记；Transitions.dev 支持用 transform/opacity/轻微 blur 表达 panel reveal，并在 reduced-motion 下即时收敛。参考只提炼模式，不复制代码。

## 已确认的融合方向

采用“**A 定气氛、B 定首屏、C 定内容结构**”的融合方案：

- **A「暗幕与红线」定气氛**：暗色是少数权力节点的叙事切场；深红是章节线、焦点线和选中状态，不是全站按钮色。
- **B「三联海报主导」定首屏**：以 `assets/posters/godfather1.jpg`（《教父》I）作为中央主海报，因它对应站点主题和三部曲入口；II、III 作为两侧次级海报，以不等量尺度、错位和前后层级形成第一视觉。三张均保留完整比例、编号、可点击查看和原始图片。
- **C「家族权力地图」定内容结构**：人物、时间线、史实和符号用跨栏标题、纵向编号、结构线、焦点/次级层级和非对称留白建立信息地图；不虚构人物关系线，不改数据语义。

暖纸仍是规则、人物、史实、符号和全文的主要阅读面；暗色集中在开场、时间线/权力转折、主引文与结尾等经过设计的段落，不恢复全站黑底、不增加主题切换。

## 需求

- R1：首屏形成明确的视觉焦点顺序：大标题/引导语、三联海报主视觉、进入档案动作和编号信息不再等量竞争；海报有前后层级和错位，但不裁切破坏原始比例。
- R2：首页形成至少三段可辨识的叙事节奏：暗色开场、亮面档案阅读、以 `.timeline-section` 为明确载体的暗色权力/引文停顿、亮面查证或人物内容、暗色结尾余波；每段的前景/背景配对明确。时间轴只改变视觉 surface/线/节点，不改变单轨几何、数据或交互。
- R3：红线只承担结构、章节切场、选中和焦点反馈；不使用全局红色渐变、发光或装饰性红色噪声。
- R4：人物、时间线、史实、符号保持完整数据和语义对应，通过尺度、编号、跨栏、边界线和图片空间建立“家族权力地图”感；不新增虚假的关系图或重复内容。
- R5：全文页不复制首页舞台化构图；保持暖纸正文、稳定标题行组、目录轨道、完整原文和人物标注，只在 hero、章节边界、引用/目录状态使用克制的墨褐/酒红结构。
- R6：保留现有搜索、时间轴拖拽、规则/引文切换、人物同页详情、图片查看器、嵌套 Escape、焦点/inert/滚动锁、URL/hash/history、reduced-motion 和图片比例契约。
- R7：保留并明确进入/激活/退出反馈；新构图动效只使用现有 CSS 状态、IntersectionObserver、Morph/FLIP 或有限 transform/opacity/blur，不增加持续自动视差或不可控闪烁。
- R8：正式设计范围为桌面端 `1920×1080`、`1440×900`、`1024×900`；窄视口仅保留历史防回归，不新增移动端设计。

## 验收标准

- AC1（首屏焦点）：三种正式桌面视口首页首屏均能确认标题、中央主海报 I、两张次海报 II/III、CTA 和编号层级；三张海报的真实点击区域和 CTA 均无遮挡，海报自然比例保持、无遮挡不可达、无横向溢出。
- AC2（叙事节奏）：首页截图可区分暗开场、暖纸内容、暗权力/引文段和暗结尾；没有恢复灰绿主导、全站黑底或全局滤镜。暗/亮表面的文字与控件对比度按实际合成背景检查：普通文字 ≥4.5:1、大字 ≥3:1、焦点/必要控件 ≥3:1。
- AC3（内容地图）：人物、时间线、史实、符号模块在三种视口均有可验证的主次/编号/结构线或非对称布局；完整内容、来源入口、稳定 ID 和既有按钮数量不减少。
- AC4（全文保真）：全文页正文、标题/引文行组、目录末项、人物标注、长表格和图片自然比例保持；无新增裁切、孤立单字、正文溢出或不可达弹层。
- AC5（交互与动效）：现有完整 Playwright 回归通过；搜索、引文、规则、时间轴、人物详情、图片缩放/全屏/嵌套关闭和 reduced-motion 均保持原契约。搜索、人物详情和 viewer 只做回归，不作为本轮重设计对象；主题状态至少新增首屏构图、暗段前景、红线焦点和全局溢出断言。
- AC6（证据）：三种正式视口记录真实 CSS viewport、DPR、字体状态/声明字体栈；截图等待 reveal、opacity/transform、引文切换和图片状态稳定，页面/控制台/请求错误为零；稳定截图供用户确认视觉方向。
- AC7（交付边界）：`npm run build`（末尾包含 `verify:deploy`）、`npm run verify:deploy`、脚本语法、任务校验和 `git diff --check` 通过；源 Markdown、生成数据语义、图片、URL/人物映射和部署配置无实质变化。

## 范围外

- 不修改源 Markdown、生成数据语义、人物映射、图片文件或部署配置。
- 不迁移框架、不引入外部字体/CDN/运行时依赖，不复制参考站代码。
- 不删除或总结原文，不修改稳定 ID，不重写人物、搜索、图片查看器或返回恢复算法。
- 不把窄视口变成移动端交付，不新增主题开关，不推送或部署线上环境。

## 风险与待确认项

- 海报错位/放大可能造成点击区域、标题行组或 1024px 边界冲突；实现必须先验证几何和可达性，再调整尺度。
- 暗色段落增加后可能造成全站过暗；暗段数量、面积和连续长度须由截图与对比度共同约束，保留暖纸主体。
- 装饰结构线不能被误读为真实人物关系；所有新增线条只表达章节/层级，不承载未存在的数据关系。
- 本轮规划已完成并已获“继续”批准，任务已进入 `in_progress`；产品实现和验证已完成，当前只等待用户对稳定截图与视觉方向做最终确认，确认前不归档。

## 高级感反馈与待决策方向

用户在查看当前实现后反馈“视觉冲击力仍不够高级”。这不是对内容完整性或交互契约的否定，而是对视觉层级、材质克制度、文字与影像关系的进一步审美反馈。基于最新真实截图，当前待验证的两个方向是：

- **A「精品电影刊物」**：保留暗色和大比例影像，但把人物文字从照片上移出，减少同时竞争的编号/边框/统计层，使用更强的编辑版式和清晰的图文分离；冲击力较强，收藏感取决于细节克制。
- **B「电影馆藏」**：使用更安静的暖纸、统一画框和目录式人物信息，建立馆藏/画册感；秩序和高级感更强，但首屏戏剧冲击会相对减弱。

已生成使用真实本地图片和实际中文文字量的静态草案：`research/premium-editorial-draft.html`、`research/archive-gallery-draft.html`。A/B 高级感方向仍待用户选择；本轮先按用户明确指出的卡片外框问题完成局部修正：人物焦点区采用等宽等高陈列框，符号区采用三等分等宽卡片，保留自然行高与完整正文。
