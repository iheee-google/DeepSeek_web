# 电影感与视觉冲击力研究

## 1. 电影视觉依据

### Gordon Willis / American Cinematographer
来源：
- https://theasc.com/article/the-godfather-on-location-gordon-willis-cinematography/

可核对的原文要点：
- Willis 将《教父》的整体感觉描述为 `brown-and-black in feeling`，并说偶尔接近 `1945 blue-black`。
- 他强调有时让画面处于“看得见与看不见的边缘”，不是把所有信息平均照亮。
- 他明确反对把同一种处理机械地贯穿全部地点：纽约的破旧棕褐、Hollywood 的清晰明亮、西西里的温暖奶油感应形成区别。
- 这套视觉不是靠装饰堆叠，而是先保留场景本身，再用曝光、空间和对比让观看有立场。

对本项目的转译：
- 暗色应该是权力节点和叙事切场，不是全站背景。
- 冲击力来自明暗段落之间的切换、影像尺度和不可平均化的留白；不通过全局 sepia、全局颗粒或统一降饱和解决。
- 暖纸亮面可承载“家庭/档案/查证”，深色段落承载“书房/交易/代价”；两者必须形成明确节拍。

### 官方/馆藏身份资料
来源：
- Library of Congress poster record: https://www.loc.gov/item/97504828/
- Paramount official film page: https://www.paramountpictures.com/movies/the-godfather

边界：馆藏记录可确认电影海报的历史对象，Paramount 可确认电影身份与官方入口；本轮对 Library of Congress 页面仅取得搜索元数据/受限响应，未把它写成已完成的海报色彩审阅；也不把搜索中的周年海报、二手配色或任意衍生海报当成 1972 年原始色板依据。现有三张本地海报仍是产品内容资产，视觉增强只能改变布局、比例和周围空间，不能替换或重绘。

## 2. 编辑式 UI 参考

### Dark Editorial reference
来源：
- https://chrislemke.github.io/website_designs/designs/Dark_Editorial.html

边界：这是通用设计观点/示例页面，不是本项目已经验证的成熟 UI 案例；仅将下列原则作为构图假设，最终以本地截图和用户审美确认决定。

可借鉴的结构原则：
- 多层近黑而非单一纯黑，用表面差异形成空间深度。
- 大标题、宽留白、非对称栏位和全幅/大比例摄影让图片成为视觉事件。
- 酒红、象牙或低饱和金属色只承担结构标记和重点，不作为到处出现的装饰。
- 文字层级首先由尺寸、字重、字体角色和空间表达，颜色只辅助层级。
- 暗面仍须保持正文对比度；“暗”不能等价于低可读性。

本项目边界：该页面是设计参考，不是项目规范；不复制其代码、字体或深色全站方案。

### Transitions.dev
来源：
- https://transitions.dev/transitions/panel-reveal/
- https://transitions.dev/transitions/tabs-sliding/

可借鉴的结构原则：
- panel reveal 用 transform、opacity、轻微 blur 同步表达“内容进入/退出”，而不是突然出现。
- sliding tabs 用连续指示器表达状态归属。
- reduced-motion 下切换为即时状态。

本项目边界：保留现有原生 DOM、Morph/FLIP、panel reveal 和 reduced-motion 契约；不复制 React 实现，不引入运行时依赖，也不为制造冲击力增加持续自动动画。

## 3. 当前代码与画面证据

- 当前生效的首页 hero 样式（`index.html` 约 `187–300`，并结合文件后置样式与稳定截图核对）已经有三张海报、暗色背景、超大标题和轻微海报漂移，但三张海报尺寸/位置接近同一展示层，标题与海报之间仍是左右两栏关系，缺少“海报穿过标题/标题压入影像”的主次关系。
- `index.html:302–307` 的共享 section 采用统一的大间距和同一标题模板；这保证节奏，但也使规则、人物、史实、符号的视觉重量趋同。
- `index.html:423–455` 的时间轴和引文已有暗色/结构线基础，可承担第一次权力切场，但需要更明确的入口、节点尺度和红线逻辑。
- `index.html:747–775` 的人物、史实目前仍以亮面网格/证据带为主；不应全部改黑，而应通过人物焦点图、局部暗色人物层或跨栏影像建立一次强烈对照。
- `index.html:492–500` 的结尾已有暗色剧照和极大标题，说明结尾可以作为第二个叙事高潮；首屏和结尾需避免使用完全相同的构图模板。
- 实际 1440×900 首页截图显示暖纸导航、近黑首屏、左侧大标题和右侧三张海报；颜色已统一，但标题/海报/空白的戏剧关系不足，用户因此反馈“太平淡”。

## 4. 设计推导

A「暗幕与红线」的首版设计系统应包含：

1. **首屏主导关系**：`godfather1.jpg`（《教父》I）固定为中央主海报，标题不再只是左栏文本；II/III 形成两侧回声，三张海报使用前后层级和不等量尺度，局部越过结构线或标题安全区，但保留完整比例和可读 CTA。
2. **红线作为叙事结构**：深红只用于章节切场、关键节点、活动选择和影像边界，避免把每个按钮都染红。
3. **第一次暗切**：现有 `.timeline-section` 与主引文形成暗色连续段，前后亮面有明确的纸色过渡，不让每一节独立漂浮；时间轴的数据、单轨几何和拖拽只做回归，不改语义。
4. **亮面内容的非对称性**：规则、人物、史实、符号保持暖纸，但通过跨栏标题、焦点人物尺度、图片与正文错位，打破相同卡片矩阵。
5. **第二次暗切**：结尾保留暗影剧照，但标题、编号和底部信息采用与首屏不同的重心，形成“余波”而非复制开场。
6. **全文对应**：全文页不复制首页舞台化构图；以暖纸正文为主，在 hero、目录轨道、引用或章节切换处使用少量深红/墨褐结构标记。

## 5. 不采用

- 全站黑底或把每个模块交替做成黑白主题。
- 全局红色渐变、发光、扫描线、颗粒或 sepia 作为“电影滤镜”。
- 通过裁切海报、压缩正文、删除内容、缩小字号制造视觉空间。
- 复制参考站 CSS/React、引入外部字体或把参考站作为运行时依赖。
