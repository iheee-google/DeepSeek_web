# 暖纸与暗书房：技术设计

## 1. 边界
只改变视觉呈现。保持 `archive.js → 两页 DOM → 现有事件/observer` 数据流，不修改生成器、源 Markdown、人物别名、URL、关闭/全屏算法或部署链。两页与共享图片层属于一个可整体验收的视觉系统，不拆成不同交付任务。

依据：`research/visual-direction.md`；用户已选 A。规划尚未授权实施。

## 2. 共享视觉角色
新增 `assets/css/archive-theme.css`，只定义跨两页复用的设计 token；页面保留本地模块样式，不抽取整个旧 CSS，不增加运行时主题管理器。

| 角色 | 候选色/规则 | 用途 |
| --- | --- | --- |
| paper | #F1E7D4 | 主阅读底 |
| paper-raised | #F8F1E4 | 搜索、详情、卡片亮面 |
| paper-deep | #E5D5BC | 次级带状区/索引底 |
| ink | #241C17 | 亮面正文 |

| study | #191512 | 开场与引文暗面 |

以上为实现起点，不是未经测量的对比度结论；允许为达标小幅调整亮度，不能换成另一视觉方向。

采用表面/前景配对与场景作用域，避免新暗面误继承全局深色文字。现有 `--ink` 实际表示背景、`--paper` 表示文字，名字与亮主题语义相反；保留它们作为页面内兼容别名，不在本任务重命名所有引用。新 token 语义明确，由页面 alias 映射消费；`--gold` 不再同时承担金属装饰与所有动作色，装饰使用单独 amber token。

样式加载：共享 token CSS 放在页面本地样式之前；页面本地根变量映射至共享 token，检查后置覆盖和硬编码的 surface/text/background/filter/border/shadow，而不是在文件末尾无限堆第三套全局主题。仅替换本任务涉及的主题声明，不做无关样式清理。

## 3. 模块画面
- 固定/粘性导航：统一暖纸高不透明表面与深墨文字。暗开场位于其下，避免为导航换色引入 scroll JS 或动态主题判断；滚动状态保留原高度和交互。
- 开场：study 底、象牙标题、胡桃/琥珀细线，保留三张海报位置与原始比例。光感限制在背景局部、不能覆盖图片和正文；不新增无语义场景图。
- 规则与全文入口：暖纸及少量 raised 表面，酒红选中指示；共享规则正文和自然高度不变。
- 时间轴：亮面，细线与节点提高可见性；保留单轨坐标、拖拽与 summary/detail，不修改轨道几何算法。
- 主引文：study 暗面作为叙事停顿；两侧引号用 amber，中文象牙、英文/来源用高对比辅助色；九条 ID 的行组、成对字符与 aria-label 不变。
- 人物、史实、符号和结尾：回归亮面档案；摄影暗部承担影像张力，不给整区加灰绿遮幕。证据带保留上下全宽、紧凑元信息和完整正文。
- 全文：暖纸底、墨褐正文；目录/表格/引用使用纸色阶。保留标题行组和已放大的辅助字号，链接酒红并有下划线；保留海报真实比例预留。
- 首页 reader、搜索、全文 person-detail：暖纸窗口、深褐文字与棕黑遮罩；正文不变、关闭入口始终可到达，不增加确认框或跳转。
- 图片查看器：当前 `assets/css/image-viewer.css:3–8` 继承浅面 token，暗遮罩并不等于深色窗口。改用独立深色 viewer token，工具栏/状态/焦点同时配套；只改 CSS，不改共享 JS 的关闭、序列号、全屏或 zoom。

## 4. 材质、字体和动效
- 用细线、暖纸色阶、清晰留白与克制阴影表达纸/木，而非真实木纹大背景或全局 sepia。
- 全局颗粒/暗角不得让正文蒙灰；局部纹理只作装饰且不吞噬对比度。移除主题相关的绿色光晕/表面，不删除状态反馈。
- 使用现有本地/系统字体栈，不引入字体请求；标题/引文大小和行组优先保持，确需微调先以真实 Range 几何证明。
- 本任务不以电影固定机位为由删除现有动画；保持 reveal、text-swap、panel-reveal、Morph/FLIP。图片即时关闭保持即时，reduced-motion 沿用即时状态。

## 6. 兼容、风险与回退
- 风险：首页早期黑金与后期浅色覆盖并存，仅改 root 会漏掉硬编码；按模块核对实际 computed style，不全局替换 hex。
- 风险：暗引文与海报卡片的文本可能继承亮面 ink；明确暗面/照片 overlay 前景，不使用全局浅/暗继承猜测。
- 风险：暗面字号虽大仍需验证英文和元信息；普通文本 4.5:1、大字 3:1、必要控件/焦点 3:1，透明背景按实际祖先合成，图像上文字须有稳定遮罩或独立底。
- 风险：改 padding/border 可能扰动既有行组、轨道与弹层；优先颜色/表面/视觉层级，几何调整仅限可证明必要处，不让视觉优化变成交互重构。
- 无线上迁移或数据变化，无自动推送。若方案实际画面不符合，先展示截图并收敛视觉差异，不以“通过测试”代替用户审美确认。
- 回退范围为本任务 scoped 视觉文件/新增 token 与对应测试；保留已有用户未跟踪文件，不执行清理、删除或重写历史。任何破坏性回退另取确认。
