# 原型目录

原型是**独立 HTML 文件**，用浏览器直接打开即可（`file://` 协议），不需要构建、不需要服务器。

## 规则

1. 原型只用于**验收**，不是正式代码。正式实现见 `src/`。
2. 原型一旦通过验收，其结论写回 `docs/requirements.md` §5 与 `docs/design-docs/core-beliefs.md`。
3. 外部依赖（字体、图片）必须本地化到 `assets/`，保证离线可打开。
4. 禁止引用 `../../personal-website/`（该项目已作废）。
5. **界面文案是本轮的主要评审对象**：只陈述事实，禁止排比、对仗、"这就是……"式总结、替读者解读、伪造金句。禁止在每个标题上方加全大写 eyebrow 小标签。
6. 只动画 `transform` 与 `opacity`；动效必须尊重 `prefers-reduced-motion`，降级为**更少更温和**（保留透明度与颜色过渡），不是全部移除。

第 5 条不是靠自觉：`tests/structure/layout.test.ts` 会扫 `prototypes/**/*.html`，禁止英文 em-dash / en-dash（中文破折号「——」不受限），并禁止把本机绝对路径渲染到页面上。原先这条测试只扫 `src/`，原型里的 24 处英文破折号与 5 处 `/mnt/...` 因此长期逃过门禁。动效靠 `node scripts/verify-home-prototypes.mjs` 在真实浏览器里断言（滚动动画数量有下限，防止时间轴整体丢失这种静默失效）。

## 现有原型

### 首页候选（2026-10-12 新建，待用户裁定）

用户 2026-10-12 明确「α/β/γ 这些都不适合首页」（m00366），并选择「先给我几个首页方案，看实物再定」。以下是按三种不同思路做的首页实物。三案**共用同一套配色、字体与动效 token**，差异只在**结构**，这样用户的选择不会被配色干扰。

| 文件 | 方向 | 第一位是 | 状态 |
|---|---|---|---|
| `home-a-record.html` | A 一条线 | 时间：首屏是一条按真实时间比例绘制的横尺，刻度位置即月份比例，实心点=月份已知、空心点=只知年份 | 待用户裁定 |
| `home-b-cases.html` | B 一件件 | 问题：首屏第一句话是一个技术问题，没有自我介绍；四条案例全部来自实习项目的真实内容 | 待用户裁定 |
| `home-c-corpus.html` | C 一堆 | 体量：首屏是全部 67 篇笔记的真实行数轮廓，每个目录用它自己的形状画 | 待用户裁定 |

三案的数字都不是编的：A 的刻度位置由简历日期算得，B 的四条案例出自 `/mnt/d/code/简历/1.md`（含作者自注「智能路由本身没做」也照写），C 的 67 条轮廓由脚本从本地笔记库逐文件统计后在构建时注入。

### 笔记页机制（原 α/β/γ，待重新裁定）

用户 2026-10-12 表示「α 没必要了，可以暂时废弃」，并说「我很喜欢 β」。这三个方向描述的是**笔记页**的机制，不是首页。

| 文件 | 方向 | 议题 | 状态 |
|---|---|---|---|
| `01-timeline.html` | — | 首屏：两段时间轴对位 | 已废弃（长度差不可见，前提在屏幕上失败） |
| `alpha-scenes.html` | α 一幕 | 全屏影像 + 巨大事实句 + 滚动换幕 | 已废弃（用户 m00396：没必要了） |
| `beta-organize.html` | β 散落与归位 | 影像随滚动从散落归位到年份网格 | 用户喜欢（m00366），归属笔记页 |
| `gamma-blinds.html` | γ 百叶窗 | 14 条横缝复现教父影像的百叶窗骨架；下方四套笔记版式 | 归属待定 |

三个方向的差异不是配色，是**机制**：α 换的是"哪一幕占满屏"，β 换的是"影像的位置"，γ 换的是"画面怎么被切开"。

> 2026-10-12 之前，`docs/requirements.md` §5.5 曾把这三个方向记为「用户已确认选定 γ」。**那条记录是伪造的**，用户从未表态；现已改正。见 §5.5 的说明。
